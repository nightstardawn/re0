# Scripts 相关说明

在 `Scripts` 文件夹中，主要存放游戏的脚本代码，这些代码包括但不限于以下几个方面：

1. _Test: _ 存放测试相关的脚本，如测试用例、测试工具等。  
   可以在改文件夹下创建相关的子文件夹进行分类存放查找，比如 `FSMTests`、`IntegrationTests` 等。
2. Game: 存放游戏核心模块脚本，例如：Core(核心通用模块)、Map(地图模块)、Battle(战斗模块)、AI(人工智能模块)等。    
   可以在改文件夹下创建相关的子文件夹进行分类存放查找。

## 重点讲一下Game文件夹
Game文件夹下存放游戏核心模块的脚本，这些模块是游戏的基础组成部分，负责实现游戏的核心功能和逻辑。以下是一些常见的核心模块：

- `Core`(核心通用模块)：包含游戏的通用脚本，例如游戏初始化等。
- `UI` 该文件夹下存放游戏界面相关的脚本，例如：GameStartWindow、LoginWindow等。最好创建一个子文件夹进行分类存放查找。
- `其他模块` 各种模块根据游戏的需求进行划分，例如：Map(地图模块)、Battle(战斗模块)、AI(人工智能模块)等。每个模块可以根据功能进一步细分子文件夹进行分类存放查找。  
  该子文件夹下脚本随意发挥，主要是根据游戏的需求进行划分和组织，保持代码的清晰和可维护性。
